# Облікові записи та профіль користувача

## Цілі

- Безкоштовна локальна реєстрація та вхід через ASP.NET Core Identity/PostgreSQL замість admin/12345.
- Захищена HttpOnly cookie-сесія, CSRF-захист змін, обмеження спроб входу, перевірка паролів і безпечні відповіді API.
- Відновлення сесії після перезавантаження, серверний вихід, захищений профіль; спортивні сторінки доступні гостям.
- Збереження мови, теми й обраних пілотів/команд для окремого користувача в БД; інтерфейс шістьма мовами.
- Міграції без пошкодження спортивних даних і журналу прогнозів; інтеграційні тести ізоляції, реєстрації/входу/виходу, CSRF та збереження налаштувань.
- Перевірити frontend, backend та живий UI; оновити документацію. Новий етап не комітити автоматично.

## Нотатки

Користувач погодив безкоштовну реалізацію. Переклади опубліковано в master (0941bb8, e8e8793). Ця задача не підключає платні послуги, OAuth, SMTP, підтвердження пошти, відновлення пароля, підписки чи публічний хостинг. Паролі хешує Identity; токени сесії не зберігаються в localStorage. Стандартні пакети Microsoft з офіційного NuGet, без російських залежностей.
Виконано: Identity/PostgreSQL, cookie/CSRF, rate limit/lockout, реальні форми та захищений профіль, автозбереження мови/теми й обране. 109 backend-тестів на ізольованих схемах PostgreSQL, 123 frontend-тест, три axe-перевірки jsdom та 773 повідомлення успішні; production build без попереджень. Backup перед міграцією; живі вхід/вихід/повторний вхід і відновлення після restart API перевірені. Шість мов, теми та 320 px перевірені, накладання кнопок на мобільному екрані виправлено. Пошта/OAuth/MFA й персональна головна залишені наступними етапами. [Контракт і межі](features/user-accounts.md). Авторизація ще не закомічена.
