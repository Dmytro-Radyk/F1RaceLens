# Підключення GitHub і початкова публікація проєкту

## Цілі

- Ініціалізувати локальний Git-репозиторій зі збереженням наявних файлів.
- Перевірити ігнорування локальних налаштувань, залежностей і результатів збірки.
- Успішно виконати збірку та наявні тести frontend перед першим комітом.
- Підключити GitHub і створити приватний репозиторій `F1RaceLens` в особистому акаунті користувача.
- Опублікувати проєкт, налаштувати `origin` і відстеження гілки `master`.

## Нотатки

- Задача погоджена користувачем 2026-10-17. Приватний доступ обрано за замовчуванням.
- Початкова публікація включає поточну реалізацію frontend і документацію.
- Авторизацію GitHub користувач підтверджує у браузері; паролі й токени не додаються до репозиторію.
- Наступні задачі виконуються в окремих гілках відповідно до `context/ai-interaction.md`.

## Історія

- 2026-10-15 — Реалізовано форми входу й реєстрації з валідацією, заглушками зовнішньої авторизації та сервісами для майбутнього JWT API; додано тимчасовий вхід `admin` / `12345`, адаптивний український інтерфейс і перевірено збірку та тести.
- 2026-10-13 — Додано кореневий `.gitignore` для .NET, Angular і локальних файлів; перевірено правила Git та збірку frontend.
- 2026-10-13 — Реалізовано загальний каркас F1 Race Lens: ліве меню, порожню робочу область, мобільну навігацію та перемикач теми. Перевірено збіркою, тестами й у браузері.
