# Історичні сезони

## Цілі

- Додати вибір календаря сезону від 1950 року до поточного.
- Зберігати вибраний рік у URL, підтримати прямі посилання та повернення зі сторінки Гран-прі.
- Скидати фільтр при зміні року; дозволяти зміну сезону під час помилки або завантаження.
- Пояснювати неповноту історичного розкладу без вигаданих даних.
- Перевірити збірку, автоматичні тести та доступність UI.

## Нотатки

Використовуємо наявний API /api/seasons/{season}/calendar і кеш; завантажуємо лише вибраний сезон. Результати гонок — окрема наступна функція.
