## Історія

- 2026-10-18 — Додано видимі підказки точок графіка з Гран-прі, стартом, фінішем або статусом. Підтримані наведення, клавіатура, Escape, натискання на телефоні, збіг старту/фінішу, краї графіка й прокручування без обрізання підказки. Збірка без попереджень; 50 тестів frontend і 6 перевірок axe успішні. Документацію оновлено; дані й API не змінювалися.
- 2026-10-18 — Реалізовано список і профіль пілота за сезоном: біографія, авторитетні показники заліку, результати гонок та доступний SVG-графік старту й фактичного фінішу з розривами для сходів/пропусків. Додано посилання зі заліку й результатів, збереження року в навігації, нормалізований API з пагінацією та кешем без продовження старих даних заліку. Підготовлено план PostgreSQL з трансферами, shared-car записами, знімками й сирими імпортами. Збірки без попереджень; 56 тестів backend, 46 frontend і 10 перевірок axe успішні.
- 2026-10-17 — Реалізовано турнірні таблиці пілотів і команд із вибором року та збереженням сезону між календарем, Гран-прі й заліками. Додано нормалізований API Jolpica з повною пагінацією, кешем, актуальним номером етапу та обробкою помилок. Підтримано трансфери, дробові/від’ємні очки, дискваліфікації й відсутні історичні заліки. Збірки без попереджень; 43 тести backend, 36 frontend і 11 браузерних перевірок axe успішні, зокрема всі 103 пілоти сезону 1952. Оновлено README й документацію.
- 2026-10-17 — Реалізовано результати Гран-прі: вкладки гонки, кваліфікації та спринту за наявності, прямі посилання й мобільні таблиці. Додано нормалізований API Jolpica з валідацією, кешем, позначенням застарілих даних і повторною спробою. Підтримано історичні пропуски, дробові очки, статуси та майбутні сесії. Збірки без попереджень; 29 тестів backend, 26 тестів frontend і 9 браузерних перевірок axe успішні. Оновлено README й документацію API та фічі.
- 2026-10-17 — Додано архів календарів від 1950 року: вибір сезону зі збереженням у URL, скидання фільтра, навігація назад до року зі сторінки Гран-прі та пояснення неповноти історичних сесій. Реальні календарі 1950 і 2025 років перевірено у браузері; production-збірка без попереджень, 20 тестів frontend і 7 перевірок axe успішні. Оновлено README, опис продукту та документацію архіву.
- 2026-10-17 — Реалізовано календар поточного сезону з реальними даними Jolpica через ASP.NET Core API (.NET 10), фільтри етапів, найближчий Гран-прі та сторінку етапу з фактичним розкладом сесій і місцевим часом браузера. Додано гостьовий доступ, прямі маршрути, кеш із позначенням застарілих даних та обробку помилок. Збірки frontend і backend пройшли без попереджень; успішні 15 тестів backend, 14 тестів frontend і 15 браузерних перевірок axe. Оновлено інструкції запуску та контракт API.
- 2026-10-17 — Узгоджено дизайн у червоно-біло-вугільній палітрі: оновлено авторизацію та навігацію, додано спільну темну тему за замовчуванням зі збереженням вибору й доступне мобільне меню. Задокументовано правила UI та рекомендовану наступну функцію — календар сезону зі сторінкою Гран-прі. Перевірено production-збірку без попереджень і всі 7 тестів на Node.js 24.15.0; 15 браузерних перевірок axe пройдено без порушень.
- 2026-10-17 — Підключено GitHub через GitHub CLI, створено приватний репозиторій `Dmytro-Radyk/F1RaceLens` і опубліковано початковий проєкт у гілці `master`; налаштовано `origin`, додано кореневий README та ігнорування локальних налаштувань Codex. На Node.js 24.15.0 успішно перевірено production-збірку й усі 4 наявні тести frontend.
- 2026-10-15 — Реалізовано форми входу й реєстрації з валідацією, заглушками зовнішньої авторизації та сервісами для майбутнього JWT API; додано тимчасовий вхід `admin` / `12345`, адаптивний український інтерфейс і перевірено збірку та тести.
- 2026-10-13 — Додано кореневий `.gitignore` для .NET, Angular і локальних файлів; перевірено правила Git та збірку frontend.
- 2026-10-13 — Реалізовано загальний каркас F1 Race Lens: ліве меню, порожню робочу область, мобільну навігацію та перемикач теми. Перевірено збіркою, тестами й у браузері.
