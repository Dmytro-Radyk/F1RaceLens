# Current Feature

## Цілі

## Нотатки

Погоджений обсяг реалізований і перевірений; 19.10.2026 користувач дозволив локальний коміт після перевірки Markdown. Злиття й публікація потребують окремої команди.

Наступні погоджені напрями: БД після головної; окремий вибір скрипта/ML на сторінці прогнозів; уточнення вимог до чат-бота з RAG. Вони ще не реалізовані. Відступи стрілок списків уже виправлені.

Поточні перевірки: production build frontend, build backend, 91 frontend-тест, 86 backend-тестів, 44 ML-тести. Деталі й обмеження — у контрактах нижче.
