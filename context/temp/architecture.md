Система складається з таких основних компонентів:

- **Клієнтський вебзастосунок** на Angular, призначений для кінцевих користувачів.
    
- **Адміністративний вебзастосунок** на Angular для керування системою та її даними.
    
- **Бекенд-сервіс** на платформі .NET, який реалізує бізнес-логіку та надає API для клієнтського й адміністративного застосунків.
    
- **PostgreSQL** — основна база даних системи.
    
- **Redis** — сховище кешованих даних, що допомагає зменшити навантаження на базу даних і пришвидшити обробку запитів.
    
- **Окремий набір фонових завдань** для інтеграції із зовнішніми API. Завдання запускаються за розкладом, отримують інформацію про завершені етапи та зберігають результати через бекенд-сервіс або безпосередньо в базі даних — залежно від реалізації.
    
## Взаємодія компонентів

Клієнтський та адміністративний застосунки взаємодіють із бекенд-сервісом через API. Бекенд обробляє запити, виконує бізнес-логіку, зберігає основні дані в PostgreSQL і використовує Redis для кешування.

Фонові завдання запускаються за визначеним розкладом та звертаються до зовнішніх API. Вони отримують актуальну інформацію про завершені етапи й передають її бекенд-сервісу для подальшої обробки та збереження.
