# Реалізація форм входу та реєстрації

## Опис

Додати до Angular-застосунку форми входу та реєстрації. Вони мають підготувати інтерфейс до майбутнього підключення JWT-авторизації без реалізації бекенду.

## Деталі

- Розмістити форму в окремому компоненті: ліву частину заповнити акцентним кольором застосунку, праворуч розмістити поля введення логіну та пароля.
- Забезпечити перехід між формами входу та реєстрації.
- Додати валідацію полів і зрозумілі повідомлення про помилки. Не дозволяти надсилати невалідну форму.
- Показати заглушки для входу через Google і GitHub.
- Додати до форми входу посилання для скидання пароля.
- Створити Angular-сервіси та типи даних, які можна буде використати для підключення входу й реєстрації через JWT API.

## Граничні випадки та обмеження

- Бекенд у межах задачі не реалізовується.
- Вхід через Google і GitHub та скидання пароля залишаються заглушками.
- Успішна перевірка форми сама по собі не означає авторизацію користувача.

## Критерії приймання

1. У застосунку доступні окремі форми входу та реєстрації з переходом між ними.
2. На широкому екрані кожна форма має акцентну ліву частину й поля введення праворуч; на вузькому екрані вміст залишається доступним.
3. Обидві форми перевіряють введені дані, показують помилки та не надсилають невалідні значення.
4. У формі входу видно заглушки Google і GitHub та посилання для скидання пароля.
5. У фронтенді створено сервіси й типи для майбутньої інтеграції з JWT API без імітації успішного входу.
6. Застосунок успішно збирається.
7. авторизація успішна і ми переходимо до застосунку якщо ввели логін admin пароль 12345
