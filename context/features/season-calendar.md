# Календар сезону та сторінка Гран-прі

Статус: рекомендована наступна функція; реалізація ще не розпочата.

## Чому першою

Календар дає користувачу зрозумілу відповідь: коли наступні перегони й що вже відбулося. Сезони, етапи, траси та сесії також стануть основою результатів, профілів пілотів і порівнянь. Ця задача створює перший завершений шлях від зовнішніх даних через сервер до корисної сторінки.

## Мінімальний корисний результат

- Календар поточного сезону з майбутніми, завершеними й скасованими або перенесеними етапами, якщо джерело повідомляє відповідний статус.
- Картка наступного Гран-прі: назва, країна, траса й дата.
- Сторінка етапу з розкладом доступних сесій; спринтерські вікенди не мають фіксованого переліку сесій.
- Час відображається у часовому поясі користувача; невідомий час позначається як неоголошений.
- Прямі маршрути календаря та Гран-прі, коректне перезавантаження сторінок і повідомлення для невідомого етапу.
- Стани завантаження, відсутніх даних, помилки та повторної спроби. Видимий час останнього оновлення.

## Порядок реалізації

1. Узгодити контракт календаря й детальної сторінки етапу та правила доступу без авторизації.
2. Додати маршрути Angular й адаптивні компоненти за поточними правилами дизайну.
3. Підготувати мінімальний ASP.NET Core API та адаптер джерела даних. Модель збереження й спосіб фонової синхронізації погодити перед реалізацією бекенду.
4. Підключити реальні дані та перевірити календар і детальну сторінку наскрізно.

Основний кандидат — [Jolpica F1 API](https://github.com/jolpica/jolpica-f1/blob/main/docs/README.md): календар, траси, результати й турнірні таблиці. Перед інтеграцією перевірити поточні умови доступу, повноту розкладу та обмеження запитів. Обробляти відсутні поля явно; не підставляти вигаданий час або статус.

## Критерії приймання

- З календаря можна відкрити конкретний Гран-прі та повернутися назад.
- Пряме посилання на етап працює після перезавантаження.
- Звичайний і спринтерський вікенди відображають фактичні доступні сесії.
- Невідомий час, порожній сезон і помилка джерела не ламають інтерфейс.
- Темний, світлий і мобільний варіанти доступні з клавіатури.
- Збірка, перевірки контракту API та ключові сценарії календаря проходять успішно.

## Наступні кроки

Після календаря — результати кваліфікації та гонки на сторінці Гран-прі, потім профіль пілота з результатами за етапами. Після накопичення реальних даних — порівняння пілотів та пояснювані інсайти. Live timing, телеметрія, новини й Fantasy-оптимізатор залишаються поза першою функцією.
