# Профіль пілота та графік форми

Статус: реалізовано 2026-10-18.

- Список пілотів зі заліку вибраного сезону та профіль за прямим URL. Посилання зі заліку й результатів сесій зберігають рік; навігація календар/залік/пілоти переносить сезон.
- Довідкові ім’я, код, дата народження й громадянство; сезонні команди, очки, місце та перемоги — зі заліку джерела, із номером етапу цього заліку.
- Таблиця результатів гонок: етап, Гран-прі, траса й дата, команда саме на гонці, старт, класифікація, статус, час/відставання й очки. Посилання відкриває повну гонку.
- Графік стартових і фактичних фінішних позицій: різні типи ліній/маркерів, позиція 1 вгорі, розриви для пропусків і сходів. Не перетворюємо сходи на останнє місце та не обираємо вигаданий єдиний результат для кількох автомобілів одного етапу. Всі записи залишаються у таблиці.
- SVG має опис і легенду; повні значення доступні у таблиці. На телефоні графік і таблиця прокручуються в межах своїх областей без горизонтального прокручування сторінки.
- Історичні пропуски, відсутні поля, відомий пілот без результатів обраного року, 404 невідомого пілота, помилка й повторна спроба, застарілий профіль або залік обробляються явно.
- Джерело Jolpica, контрольована нормалізація й повна пагінація, кеш профілю та заліку без продовження життя старих даних. PostgreSQL до цієї задачі не підключається.

## Перевірки

56 тестів backend, 46 frontend. Збірки проходять без попереджень. Реальні профілі Норріса-2025, Фаріни-1950, Шумахера-1997, відсутні результати за рік, невідомого пілота, навігацію, зміну сезону й повторну спробу перевірено через API та браузер. 10 перевірок axe без порушень охопили темну/світлу теми, desktop/mobile, графік, список, порожні дані та помилки.

## Зберігання і наступні задачі

[Контракт профілю](../architecture/driver-profile-api.md) описує фактичні дані й правила графіка. [План PostgreSQL](../architecture/data-storage-plan.md) визначає, що потрібно зберігати: довідники, участь пілота в кількох командах, окремі записи результатів, знімки заліку та сирі імпорти. Сам графік відтворюється з даних і не є первинною сутністю бази. Порівняння пілотів, обрані пілоти та персональні налаштування — окремі наступні задачі.
