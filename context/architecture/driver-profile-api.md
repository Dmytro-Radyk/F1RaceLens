# Профіль пілота: API та графік

`GET /api/seasons/{season}/drivers/{id}` доступний гостям. Сезон: `current` або чотири цифри 1950–наступний рік UTC. Ідентифікатор: 1–80 малих латинських літер, цифр, `_` або `-`, без URL-фрагментів.

Некоректні параметри — `400`; відсутній пілот у довіднику — `404`; помилка джерела без придатного кешу — `503` Problem Details з `Retry-After: 60`. Відомий пілот без результатів обраного року повертається з `races: []` і, за відсутності заліку, `standing: null`. Порожній сезон не є доказом відсутності пілота в історії.

## Відповідь

- `season`, `updatedAt`, `isStale`, `source` — метадані зібраного профілю; `updatedAt` є UTC-часом збирання знімка, а не часом публікації джерелом.
- `driver`: `id`, `name`, `code`, `dateOfBirth`, `nationality`. Останні три поля можуть бути `null`. Біографія береться з загального довідника; вік і припущення про те, чи пілот живий, не обчислюються. Поточний постійний номер довідника не видається за стартовий номер минулого сезону.
- `standingsRound` та `standing`: останній доступний етап і рядок заліку за контрактом standings. Очки й перемоги не виводяться із суми гонок: спринти, штрафи й історичні правила можуть змінювати підсумок.
- `races`: `round`, `name`, `date`, `circuit`, `result`. `result` відповідає рядку API результатів. Всі записи зберігаються, зокрема кілька результатів одного пілота в одному історичному етапі. Відсутні поля не вигадуються.

## Джерело

Поточний рік визначається відповіддю вже наявного заліку пілотів. Далі клієнт завантажує [довідник](https://github.com/jolpica/jolpica-f1/blob/main/docs/endpoints/drivers.md) `drivers/{id}.json?limit=1` і [результати](https://github.com/jolpica/jolpica-f1/blob/main/docs/endpoints/results.md) `{season}/drivers/{id}/results.json?limit=100&offset=…` через спільний `IHttpClientFactory`, HTTPS і таймаут 12 секунд на запит.

Перевіряються ідентифікатор пілота в довіднику, фільтрі й кожному результаті; сезон, номер етапу, дати, offset, незмінність total та повнота всіх сторінок. Offset рахується за записами результатів, а не кількістю Гран-прі. Захисна межа — 1000 записів на пілота за сезон. Частковий профіль при помилці не кешується.

Кеш окремий за сезон/пілот; `current` і відповідний числовий рік ділять знімок. Свіжість — 15 хвилин, для порожніх результатів або застарілого заліку — одна хвилина. При недоступності джерела повертається позначений збережений профіль; строк придатності обмежений 24 годинами від завантаження найстарішої складової — заліку. Нове збирання профілю не продовжує життя застарілого заліку. `isStale` повідомляє також про застарілі дані заліку всередині свіжо зібраного профілю. Кеш очищається після перезапуску.

## UI та графік

`/drivers?season=2025` показує пілотів із заліку. `/drivers/norris?season=2025` — профіль. Рік зберігається при переходах до календаря, таблиць, списку пілотів і результатів Гран-прі. Пілоти у заліку та таблицях сесій мають прямі посилання на профіль.

Графік — невеликий SVG без нових залежностей, з підписом, описом, легендою та числовою таблицею нижче. По осі X — фактичний номер етапу, по Y — позиція (1 вгорі). Пунктир і квадрат позначають старт; суцільна лінія та коло — фактичний фініш. Старт не називається результатом кваліфікації.

Поверх маркерів розташовані HTML-кнопки з доступними назвами. Наведення, фокус клавіатури та натискання відкривають одну HTML-підказку з Гран-прі й коротким підсумком старту/фінішу або статусу. Escape й натискання поза підказкою закривають її; на сам текст можна перевести вказівник. Позиція обчислюється відносно видимої області графіка, а не повної ширини прокручуваного SVG. Збіг старту й фінішу не створює двох перекритих кнопок. Дані підказок похідні від результатів і не потребують окремого зберігання чи змін API.

Фінішна лінія використовує лише `Finished` та `+N Lap(s)`; інший або невідомий статус розриває її. Хрестик під графіком не має числового Y-значення. Стартова позиція 0 чи невідома не стає останньою позицією. Пропущені етапи розривають лінії; кілька записів одного етапу показуються у таблиці, без вибору «найкращого» результату для графіка. Майбутні й відсутні дані не доповнюються вигаданими точками. Це візуалізація позицій, а не прогноз чи обчислений рейтинг форми.
