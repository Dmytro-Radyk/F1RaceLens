# Турнірні таблиці: контракт API

`GET /api/seasons/{season}/standings/{kind}` доступний без входу.

- `season`: `current` або чотири цифри від 1950 до наступного календарного року UTC включно.
- `kind`: `drivers` або `constructors`.
- Некоректні параметри — `400`; недоступне чи некоректне джерело без придатного кешу — `503` Problem Details з `Retry-After: 60`. Відсутній залік — `200` із порожнім `entries`, не помилка.

## Відповідь

`season`, `round`, `kind`, `updatedAt`, `isStale`, `source`, `entries`. Поточний сезон і номер етапу визначає джерело. `round` може бути `null` для порожнього заліку. `updatedAt` — UTC-час завантаження повного знімка.

Рядок: `position` (число або `null`), `positionText`, `id`, `name`, `code` (або `null`), `teams` (масив назв), `points` (десяткове число), `wins` (невід’ємне ціле число). Для команди `code: null` і `teams: []`. Для пілота зберігаються всі унікальні назви команд за сезон. Від’ємні й дробові очки не відкидаються; власного перерахунку очок немає.

Позначення джерела `E`, `D`, `-` відображаються як «Виключено», «Дискваліфіковано», «Поза заліком». Невідомі позначення зберігаються. Числові місця сортуються за зростанням; учасники без числового місця залишаються наприкінці зі своєю класифікацією. Ідентифікатори учасників у межах одного заліку мають бути унікальні.

## Джерело та пагінація

- [Пілоти](https://github.com/jolpica/jolpica-f1/blob/main/docs/endpoints/driverStandings.md): `{season}/driverStandings.json?limit=100&offset={offset}`.
- [Команди](https://github.com/jolpica/jolpica-f1/blob/main/docs/endpoints/constructorStandings.md): `{season}/constructorStandings.json?limit=100&offset={offset}`.

Адаптер використовує налаштований `IHttpClientFactory` Jolpica з фіксованим HTTPS-хостом, таймаутом 12 секунд на запит і `CancellationToken`. Послідовно завантажує всі сторінки до `total`, перевіряє сезон, етап, offset, незмінність total між сторінками, обов’язкові поля й дублікати. Порожня проміжна сторінка, зміна знімка або обрізані дані не стають неповною таблицею. Захисна верхня межа — 1000 записів на залік. Це значно більше за перевірений історичний набір, але обмежує некоректну відповідь провайдера.

## Кеш

Ключ — сезон/вид заліку; `current` і відповідний числовий рік ділять знімок. Непорожні дані свіжі 15 хвилин, порожні — одну хвилину. Конкурентні оновлення об’єднуються. При помилці останній знімок віком до 24 годин повертається з `isStale: true`, без зміни початкового `updatedAt`; повторна спроба — через хвилину, без продовження 24-годинного строку. Кеш у пам’яті очищається після перезапуску. Частково завантажений залік не кешується.

## Frontend

`/standings?season=2025&table=constructors`; невідомий `table` відкриває пілотів. Вибір сезону доступний від 1950 до поточного року UTC; неправильний рік показує помилку без запиту API. Посилання бокового меню переносять лише рік між календарем і заліками, включно з роком із параметра маршруту Гран-прі. Query-параметри не впливають на активне виділення пункту меню. Дані заліку не підміняють дату оновлення календаря чи результатів сесій.
