# F1 Race Lens

## Ключова ідея проєкту

Застосунок для фанатів Формули-1, який об’єднує результати чемпіонату й перетворює статистику на зрозумілу аналітику. Допомагає стежити за обраними пілотами, порівнювати їхню форму та готуватися до наступного Гран-прі, зокрема приймати власні рішення у F1 Fantasy.

## Ключові можливості

MVP зосереджений на поточному сезоні та аналізі виступів пілотів:

- список обраних пілотів і профіль кожного з результатами, показниками та графіками форми;
- порівняння двох пілотів за гонками, кваліфікаціями й стабільністю;
- календар сезону та сторінка Гран-прі з даними про трасу й попередні результати;
- короткі автоматичні висновки зі статистики та контекст для самостійних Fantasy-рішень.

## Технологічний стек

- Backend: ASP.NET Core Web API, Entity Framework Core, PostgreSQL.
- Frontend: Angular, Chart.js.
- Авторизація: ASP.NET Core Identity; 
- Розгортання: Docker; 
- опис API: Scalar.

## UI/UX

Основні розділи: головна, поточний сезон (календар, таблиці, Гран-прі), пілоти, команди, порівняння, інсайти та профіль. Навігація доступна з бокового меню, є глобальний пошук.

Інтерфейс будується навколо карток, графіків і ключових показників. Важливу інформацію має бути легко знайти; кольори передають зміст змін. Основна тема — темна, світла доступна як альтернатива. Сторінки адаптуються до десктопів, планшетів і телефонів.

Основна палітра — червоний, білий і темно-вугільний. Авторизація та основний застосунок використовують спільну тему зі збереженням вибору. Деталі — у [правилах дизайну](design/ui-guidelines.md).

Перший функціональний етап — [календар сезону та сторінка Гран-прі](features/season-calendar.md) — реалізований із реальними даними Jolpica через ASP.NET Core API. Доступні також [архів календарів від 1950 року](features/historical-seasons.md) та [результати гонки, кваліфікації й спринту](features/grand-prix-results.md). Наступні етапи — турнірні таблиці пілотів і команд та профілі пілотів зі збереженням вибраного сезону між розділами.
