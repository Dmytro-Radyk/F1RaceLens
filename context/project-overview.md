# F1 Race Lens

## Ключова ідея проєкту

Застосунок для фанатів Формули-1, який об’єднує результати чемпіонату й перетворює статистику на зрозумілу аналітику. Допомагає стежити за обраними пілотами, порівнювати їхню форму та готуватися до наступного Гран-прі, зокрема приймати власні рішення у F1 Fantasy.

## Ключові можливості

MVP зосереджений на поточному сезоні та аналізі виступів пілотів:

- профілі пілотів із результатами, показниками та графіками форми; обрані пілоти — заплановані;
- порівняння двох пілотів за гонками; кваліфікації та спринти — наступне розширення;
- календар сезону та сторінка Гран-прі з даними про трасу й попередні результати;
- короткі автоматичні висновки зі статистики та контекст для самостійних Fantasy-рішень.

## Технологічний стек

- Backend: ASP.NET Core Web API (.NET 10), адаптери Jolpica/Open-Meteo, кеш пам’яті. EF Core та PostgreSQL заплановані, міграцій і постійної БД ще немає.
- Frontend: Angular; графік профілю — доступний SVG без додаткових залежностей. Chart.js залишається варіантом для наступної складнішої аналітики.
- Локальний ML: Python 3.13, LightGBM, файлові дані й ваги; окремий переглядач на 4300. Це таблична модель, не мовна модель.
- Авторизація зараз демонстраційна у frontend; ASP.NET Core Identity запланований.
- Docker і Scalar — заплановані інструменти розгортання та опису API.

## UI/UX

Основні розділи: головна, поточний сезон (календар, таблиці, Гран-прі), пілоти, команди, порівняння, інсайти та профіль. Навігація доступна з бокового меню, глобальний пошук поки вимкнений. Профіль користувача й персоналізація заплановані.

Інтерфейс будується навколо карток, графіків і ключових показників. Важливу інформацію має бути легко знайти; кольори передають зміст змін. Основна тема — темна, світла доступна як альтернатива. Сторінки адаптуються до десктопів, планшетів і телефонів.

Основна палітра — червоний, білий і темно-вугільний. Авторизація та основний застосунок використовують спільну тему зі збереженням вибору. Деталі — у [правилах дизайну](design/ui-guidelines.md).

Перший функціональний етап — [календар сезону та сторінка Гран-прі](features/season-calendar.md) — реалізований із реальними даними Jolpica через ASP.NET Core API. Доступні також [архів календарів від 1950 року](features/historical-seasons.md), [результати гонки, кваліфікації й спринту](features/grand-prix-results.md), [турнірні таблиці пілотів і команд](features/season-standings.md) та [профілі пілотів із графіком і результатами](features/driver-profile.md). Вибраний сезон зберігається між календарем, таблицями та пілотами. Реалізовані також [команди](features/season-teams.md), [порівняння пілотів](features/driver-comparison.md), [аналітика](features/driver-analytics.md) та [експериментальні прогнози актуального сезону](features/season-predictions.md). Реалізовано [головну актуального сезону](features/home-overview.md) із розкладом та лідерами. Наступний інфраструктурний етап — постійне зберігання за [планом PostgreSQL](architecture/data-storage-plan.md).

Окремий [ML-експеримент](../ml/README.md) має версії LightGBM v1–v4 та q1 після кваліфікації, [фіксацію прогнозів до старту](features/post-qualifying-forecasts.md) й ручне оцінювання після гонки. Перевага над простими базовими прогнозами ще не доведена; історичні метрики не замінюють майбутню перевірку. Інтеграція вибору скрипта/ML у `/predictions` та чат-бот із RAG ще не реалізовані.
