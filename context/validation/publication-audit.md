# Перевірка перед публікацією — 21.10.2026

Перевірено всі відстежувані та нові неігноровані файли, доступні історичні Git-блоби, метадані авторів і чотири зображення дизайн-референсів у context/Screenshots. Автоматичний пошук включав точні значення приватних SMTP/DB-секретів і адреси відправника, типові ключі/токени, приватні ключі та URL з паролями. Самі значення й рядки зі збігами не виводилися. Знайдені фіксовані паролі/токени належать лише ізольованим тестам; це не чинні облікові дані. Довідник F1DB — відкритий атрибутований набір, без користувацьких даних.

У старих метаданих комітів виявлено особисту адресу автора. Користувач окремо погодив очищення всієї історії з force-push. Для авторства використовується GitHub noreply; імена, дати, дерева файлів і зв’язки між комітами зберігаються. Локальна резервна копія до очищення зберігається тільки у приватному ігнорованому каталозі `.local/publication-backups`, доступному власнику та SYSTEM; її не публікувати. Стара копія репозиторію може повернути попередню історію — після очищення для інших комп’ютерів слід зробити новий clone.

`.local/`, appsettings.Local.json, дампи, ключі, моделі, сирі ML-дані й середовища не входять у коміт. `.gitignore` додатково захищає експорти ключів, PostgreSQL password files, дампи й Git bundle. Документацію звірено з реалізованими новинами/причинами сходу, довідниками/пошуком/історією, формами пароля/пошти та персональною головною. Виправлено застарілі згадки про ще не реалізовані користувацькі дані, числовий лічильник каруселі та неповний підсумок локалізації; локальні Markdown-посилання перевірено.

Пошук за шаблонами й відомими приватними значеннями не є математичною гарантією відсутності будь-якої конфіденційної інформації. Переписування гілок також не видаляє чужі клони, форки чи кешовані старі commit views: [межі очищення на GitHub](https://docs.github.com/en/authentication/keeping-your-account-and-data-secure/removing-sensitive-data-from-a-repository). Резервні копії, GitHub-кеші та сторонні копії не слід плутати з очищеною активною історією.

Перед комітом повторно пройшли 139 backend-тестів без пропусків, 147 frontend-тестів, обидві збірки без попереджень і перевірка 929 повідомлень локалізації. Перевірено всі 52 Markdown-файли: зламаних локальних посилань немає. Код застосунку під час аудиту не змінювався.
