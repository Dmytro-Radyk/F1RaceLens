# F1 Race Lens

Вебзастосунок для фанатів Формули-1: результати сезону, профілі пілотів, порівняння виступів і зрозуміла аналітика для підготовки до Гран-прі.

## Поточний стан

Реалізовано Angular-каркас із боковим меню, адаптивною мобільною навігацією, перемиканням теми та українськими формами входу й реєстрації.

Вхід `admin` / `12345` є лише демонстраційною перевіркою у frontend. Реєстрація, зовнішня авторизація та відновлення пароля очікують підключення сервера. Бекенд, реальні F1-дані й основні змістові сторінки ще заплановані.

## Локальний запуск

Потрібні Git, Node.js 24.15.0 або новіша сумісна версія гілки 24.x і npm 11. Вимоги Node відповідають Angular-залежностям, зафіксованим у `frontend/package-lock.json`.

```powershell
cd frontend
npm ci
npm run start
```

Після запуску відкрийте <http://localhost:4200/>.

## Перевірки

З директорії `frontend`:

```powershell
npm run build
npm test -- --watch=false
```

## Структура

- `frontend/` — клієнтський застосунок Angular.
- `context/` — опис продукту, поточна задача, правила роботи й дизайн-референси.
- `.agents/skills/` — проєктні навички для роботи з AI.
- `AGENTS.md` — початкові інструкції для AI-агента.

## Подальша розробка

Перед початком задачі оновлюємо `context/current-feature.md`, створюємо окрему гілку `feature/...`, `fix/...` або `chore/...`, реалізовуємо зміни й перевіряємо їх. Коміт робимо після успішної збірки та потрібних перевірок. Завершену гілку зливаємо в `master` і публікуємо в GitHub.

Детальний процес описаний у [правилах взаємодії з AI](context/ai-interaction.md), продукт — в [огляді проєкту](context/project-overview.md).

Локальні секрети, залежності, результати збірки й персональні налаштування Codex виключені через `.gitignore`.
