# Frontend F1 Race Lens

Angular 22, TypeScript, signals, Signal Forms і Vitest. Календар та сторінки Гран-прі доступні без входу, дані надходять із власного ASP.NET Core API.

## Запуск

Потрібні Node.js 24.15.0 або новіша сумісна версія 24.x та npm 11.

Спочатку в окремому терміналі з кореня репозиторію запустіть API (.NET 10 SDK):

```powershell
dotnet run --project backend/F1RaceLens.Api --launch-profile http
```

З директорії `frontend`:

```powershell
npm ci
npm run start
```

Відкрийте <http://localhost:4200/home>. Development-проксі з `proxy.conf.json` спрямовує `/api/**` на <http://127.0.0.1:5080>.

## Сторінки

- `/` перенаправляє на `/home`: найближчий непідтверджений Гран-прі, розклад сесій, прогрес сезону й лідери заліків. Кожне джерело має незалежні завантаження, помилку та повторну спробу.

- `/calendar` — поточний сезон, найближчий Гран-прі та фільтри етапів.
- `/calendar?season=1950` — календар вибраного історичного сезону.
- `/calendar/{season}/{round}` — траса й розклад фактичних сесій етапу.
- `/calendar/{season}/{round}?session=race` — результати гонки; `qualifying` — кваліфікації, `sprint` — спринту, якщо він є в розкладі. Вкладки підтримують прямі посилання та історію браузера.
- `/standings` — останній доступний залік пілотів поточного сезону. `/standings?season=2025&table=constructors` — залік команд вибраного року. Перемикання таблиць зберігає рік; бокова навігація між календарем і таблицями також переносить сезон зі сторінки або маршруту Гран-прі.
- `/drivers?season=2025` — пілоти зі заліку вибраного сезону; `/drivers/norris?season=2025` — біографія, сезонні показники, результати гонок і SVG-графік стартових/фінішних позицій із числовою таблицею. Вибір року зберігає пілота, посилання доступні зі заліку й результатів сесій. Сходи не з’єднуються фінішною лінією; графік не є прогнозом форми.
- `/teams?season=2025` — картки команд зі заліку конструкторів; `/teams/mclaren?season=2025` — показники команди та всі її пілоти зі заліку сезону, включно з переходами. Очки пілотів показуються за весь сезон. Обидва заліки мають окремі позначки актуальності, помилки й повторні спроби. Для 1950–1957 доступні списки конструкторів та їхніх пілотів за участю в гонках, без командних очок і місць.
- `/compare?season=2025&first=norris&second=piastri` — вибір пари, обмін місцями, офіційні очки/перемоги, середні фактичних фінішів, очний рахунок, спільний графік і результати за етапами. Порівнюються лише гонки; пояснення доступні через кнопки етапів.
- `/insights?season=2025&driver=norris&window=5` — аналітика останніх 5 або 10 етапів участі, середній і найкращий фініш, зміна позицій, порівняння з попереднім відрізком, короткі висновки та таблиця. Кожен показник має явну вибірку й правила розрахунку.
- `/predictions` — статистичний скрипт прогнозу майбутніх Гран-прі й заліків поточного сезону, очікувані очки цілими числами, модельні частки титулу/топ-3, діапазони й опис обмежень. Історичний рік не вибирається. Для неповних або неузгоджених даних відсотки не показуються.
- `/login` — демонстраційні форми входу й реєстрації. Демо-вхід: `admin` / `12345`.

Глобальний пошук поки вимкнений. Окремий переглядач LightGBM працює на порту 4300 за [ML-інструкцією](../ml/README.md); інтеграція ML і чат-бота в Angular ще не реалізована. Реєстрація, зовнішня авторизація та відновлення пароля ще не підключені до сервера.

## Перевірки

```powershell
npm run build
npm test -- --watch=false
```

Тести охоплюють форми, тему, календарні маршрути, архів, фільтри, результати сесій, турнірні таблиці, збереження року в навігації, скасування запиту при перемиканні, відсутні значення, помилки й повторні спроби. Таблиці прокручуються горизонтально на малих екранах і доступні з клавіатури.

Production-збірка міститься у `dist/frontend`. На хостингу потрібно налаштувати fallback на `index.html` для маршрутів Angular та reverse proxy `/api` до бекенду: development-проксі в production не працює.

Дивіться також [головний README](../README.md), [правила frontend](AGENTS.md), [дизайн](../context/design/ui-guidelines.md) та [контракт API](../context/architecture/calendar-api.md).


Прогнози v2 враховують статистику трас за два попередні сезони, поточну команду пілота й доступну погоду Open-Meteo. На сторінці можна задати тимчасовий сценарій дощу, поступової зміни темпу команди та заміни пілота з майбутнього етапу. Невідомі погода, оновлення й заміни не вигадуються; показники залишаються експериментальними.
